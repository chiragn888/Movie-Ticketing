
This project aims to develop a minimum viable product (MVP) that leverages Django and Django Rest Framework to offer a robust backend solution. The goal is to create a scalable and maintainable architecture that can serve as the foundation for further development.

## Prerequisites

Before setting up the project, ensure you have the following installed:
- Python (3.8 or newer)
- pip (Python package installer)

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory where the `README.md` file is located.
3. Install the project dependencies by running `pip install -r requirements.txt` in your terminal.

## Running Migrations

To set up your database, follow these steps:
1. Ensure you are in the project directory where `manage.py` is located.
2. Run `python manage.py makemigrations` to create the migration files.
3. Apply the migrations to your database by running `python manage.py migrate`.
